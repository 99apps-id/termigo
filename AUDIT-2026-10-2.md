# Termigo Deep Audit - 2026-10-02

## Scope
- Full codebase review: Rust backend (`src-tauri/`) + TypeScript frontend (`src/`)
- Focus: security boundaries, concurrency safety, sandbox allowlist, approval flow, SSRF, secret handling

## Findings

### CRITICAL-1: node_modules Corruption (Dev Experience)
**Files**: `node_modules/`, `node_modules/.pnpm/`
- `pnpm install` fails with file-lock errors on Windows (`UNKNOWN: unknown error, open '...react\package.json'`)
- `biome` and `vitest` binaries incomplete: `@biomejs/cli-win32-x64/biome.exe` missing, `@vitest/utils` not found
- Impact: `pnpm lint`, `pnpm test`, `pnpm check-types` all fail
- `tsc --version` works because TypeScript binary is intact
- **Recommendation**: Reinstall on WSL/Linux, or close file-indexing tools and retry

### HIGH-1: Shell Allowlist Absolute Path Bypass (Intentional)
**File**: `src-tauri/src/modules/shell/mod.rs:197`
- `allows_program()` returns `true` for all rooted/absolute paths
- `C:\Windows\System32\chcp.com` bypasses `SANDBOX_ALLOWLIST`
- **Status**: Operator decision (AUDIT-DEEP-2026-09-23 F-1). Allowlist is friction control for bare names, not a hard boundary. Hard guards remain: approval flow, delete gate, secret write-target refusal, deny-lists.

### MEDIUM-1: pty_close Only Kills Immediate Child (Unix)
**Files**: `src-tauri/src/modules/pty/commands.rs:205`, `src-tauri/src/modules/pty/session.rs:63`
- Unix `killer.kill()` does not kill descendants (e.g. `npm run dev` inside pwsh)
- Windows uses Job Object (`JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`) to handle this
- **Status**: Known gotcha, documented in TERMIGO.md. Not a bug, but a platform limitation.

### MEDIUM-2: Mutex Poison Crashes (11 sites)
**Files**:
- `src/launch.rs:17,22`
- `src/lib.rs:372,376`
- `src/modules/workspace.rs:41,61,71`
- `src/modules/fs/watch.rs:110,244,267`
- `src/modules/control/router.rs:371`

Pattern: `.lock().expect("... poisoned")` panics on poison, crashing the Tauri command handler.

Repo idiom elsewhere: `.unwrap_or_else(|e| e.into_inner())` for poison recovery.

**Impact**: Any panic while holding these locks crashes the app. Low probability in production, higher in dev/HMR.

### LOW-1: MCP Command Validation Base-Only
**File**: `src-tauri/src/modules/mcp/mod.rs:142`
- `validate_mcp_command` checks only the first token against `ALLOWED_MCP_COMMANDS`
- Args are not shell-parsed, but passed to the child process
- **Risk**: Low, unless an MCP server itself executes args via shell

### LOW-2: SSH Async Lock Guard Panic Risk
**Files**: `src-tauri/src/modules/ssh/session.rs:1024,1068`
- `report.lock().await.seen.clone().unwrap_or_default()`
- `async::Mutex` in Rust does not poison, but a panic inside the guard aborts the async task
- **Recommendation**: Ensure the block inside the lock cannot panic, or use `try_lock` with fallback

## Security Strengths

### SSRF / Network
- `src-tauri/src/modules/net.rs`: `ip_kind()` blocks loopback, private (unless opted-in), link-local, cloud metadata (169.254.169.254, fd00::ec2), DNS rebinding via IP pinning
- Redirect policy caps at 10 hops and re-classifies each hop

### Secret Deny-List Parity
- Frontend: `src/modules/ai/lib/security.ts`
- Backend: `src-tauri/src/modules/fs/security.rs`
- Covers `.env*`, `.ssh/`, `.aws/`, `.kube/`, credential stores, Windows system dirs (open per operator policy), `.termigo/hooks.json`, `.termigo/approvals.json`

### Shell Write-Verb Guard
- `shell_write_hits_protected_target` refuses `Set-Content`, `Out-File`, `cp`, `mv`, `del`, `Remove-Item`, etc. when target matches deny-list or `.termigo/*.json`

### PTY Safety
- All critical `.unwrap()` on locks replaced with `.unwrap_or_else(|e| e.into_inner())`
- `SPAWN_LOCK` serializes early cleanup on dev double-mount
- `CONPTY_LIFECYCLE_LOCK` prevents overlapping pseudoconsole lifecycle corruption on Windows
- Job Object kills descendant processes on Windows

### Approval Resume
- Trailing-message invariant enforced: `streamText` finds approvals only in `messages.at(-1)`
- `isResumingApproval` blocks env-block append during approval resume

### SSH TOFU
- SHA-256 fingerprint pinning, mismatch aborts handshake

## Recommendations

1. **Fix node_modules**: Reinstall on WSL/Linux, or disable antivirus/indexer and retry `pnpm install`
2. **Poison recovery sweep**: Replace `.expect("... poisoned")` with `.unwrap_or_else(|e| e.into_inner())` in all 11 sites
3. **MCP args hardening**: Ensure MCP servers do not shell-evaluate `args`; consider banning shell metacharacters in args
4. **SSH lock hygiene**: Wrap `report.lock().await` blocks in `catch_unwind` or use `try_lock` fallback
