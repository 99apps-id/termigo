# Termigo documentation

- [MCP integration](MCP.md) - configure and use MCP servers (`.termigo/mcp.json`, `termigo mcp ...`)
- [Skills](SKILLS.md) - project and user skills (`SKILL.md` folders, `termigo skill ...`)
- [Agents and providers](AGENTS.md) - Codex, Claude Code, Gemini, Ollama via `termigo agent ...`
- [Architecture](ARCHITECTURE.md) - repository layout, command surface, data layout

## Quick reference

```powershell
termigo doctor                  # inspect local tools
termigo init <dir>              # scaffold a workspace
termigo agent list              # installed agent providers
termigo skill list              # project + user skills
termigo mcp list                # configured MCP servers
```
