## Observasi Arsitektur (Positif)

1. **Defense-in-depth keamanan** - deny-list secret paths diterapkan di dua lapisan: frontend (`security.ts`) dan Rust (`fs/security.rs`), plus canonicalisasi untuk tangkal symlink traversal.
2. **WebGL lifecycle** - context loss recovery teruji (`webglRecovery.test.ts`), tidak ada leak, dan addon diparkir dengan benar saat tab tersembunyi.
3. **Subagent pool** - `yieldSlot` mencegah deadlock vertikal; batch isolation default aktif saat >=2 writer; abort signal mempropagasi dengan benar.
4. **Terminal session lifecycle** - `disposeSession` membersihkan timer, slot, write meter, dan pendengar; cleanup di `useEffect` juga memanggil `detachSession` sebagai safety net.
5. **Shell integration invariant** - `SPAWN_LOCK` + parser OSC 7/133 + never serialize mid-command dijaga dengan baik.
6. **PTY output backpressure** - `OutputCredit` membatasi buffer, mencegah OOM pada stream panjang.

## Area yang Perlu Diperhatikan ke Depan

1. **`approvalResume.ts` invariant** - `messages.at(-1)` adalah load-bearing untuk resume approval. Sudah teruji (18 test), tapi perubahan di masa depan pada message ordering harus waspada.
2. **`PaneTreeView.tsx` stale SSH spec** - saat tab diganti sangat cepat, `openSshTerminalFromSpec` bisa terbuka untuk sesi yang ditinggalkan. Saat ini ditangani oleh `disposed` flag, tapi tetap perlu pengawasan.
3. **`canonical_cache` thundering herd** - jika cache penuh (256 entry) dan semua kadaluarsa bersamaan, ada burst `canonicalize()`. Dengan TTL 1 detik, risiko kecil, tapi bisa diperbaiki dengan randomized TTL.
