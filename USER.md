# USER.md

Personal preferences and workflow instructions for the agent. Edit freely;
this file wins over `AGENTS.md` on matters of taste and workflow.

## Workflow

- Work autonomously toward the stated goal. Inspect, edit, build, and test
  without asking; all tools are available to agent and subagents.
- Keep changes focused. Explain what changed and how it was verified.
- Prefer `pnpm` scripts (`pnpm lint`, `pnpm check-types`, `pnpm test`) and
  the repo's own checks over ad-hoc commands.

## Preferences

- Concise, factual communication. No superlatives, no filler.
- No em-dash and no emojis anywhere (repo convention).
- Ground claims in real files and lines, never from memory alone.
